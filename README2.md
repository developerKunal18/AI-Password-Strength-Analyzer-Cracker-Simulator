# 🔐 AI Password Strength Analyzer & Cracker Simulator
## 💡 Overview
The **AI Password Strength Analyzer** is an offline Python application that evaluates how secure a password is by calculating its **entropy** and estimating how long it would take to crack using brute-force techniques.

This project simulates real-world **cybersecurity tools** used by ethical hackers and security engineers.

---

## 🚀 Features

### 🔑 Password Strength Analysis
- Analyzes:
  - Length
  - Use of uppercase letters
  - Use of lowercase letters
  - Numbers
  - Special characters

### 🧠 Entropy Calculation
- Measures password unpredictability
- Higher entropy means stronger security

### ⏳ Crack Time Estimation
- Estimates how long it would take to brute-force the password

### 🛡 Strength Classification
- Weak  
- Medium  
- Strong  

### 🌐 Fully Offline
- No APIs
- No internet required
- Runs locally
